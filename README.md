### 📚 요즘 이런 거 배우고 있어요

멈추지 않고 성장하는 개발자가 되기 위해 오늘도 열심히 달립니다!

- Redux Toolkit을 활용한 효율적인 프론트엔드 상태 관리를 익히며, 더 견고하고 예측 가능한 애플리케이션을 만들 계획입니다.
- 프론트엔드 전체 복습: 웹의 근간을 다지는 시간. 처음 배우는 마음으로 HTML, CSS, JavaScript, React 전반을 훑으며 깊이를 더하고 있습니다.
- 겉으로 보이는 웹 너머, 백엔드와 프론트엔드의 유기적인 연결을 위한 API 구조 설계에 대한 이해를 넓히고 있습니다.
