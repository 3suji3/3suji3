## 💻 프로젝트

### 🪨 오늘 뭐하지? — 개인 맞춤형 일정 관리 서비스

> 현재 에너지와 사용할 수 있는 시간을 기준으로
> 오늘의 시작점을 추천하는 일정 관리 서비스입니다.

`React` `TypeScript` `Cloudflare` `QA`

#### 주요 경험

- 실제 배포 환경에서 기능을 반복적으로 사용하며 문제 발견 → 수정 → 재검증
- 일정 등록 후 상태 미반영, 날짜/시간대 오류, 반응형 UI 문제 등 개선
- 기능 변경 시 기존 사용자 흐름에 미치는 영향을 함께 확인
- 발견한 문제와 개선 과정을 날짜와 함께 README에 지속적으로 기록

🔗 [Repository](https://github.com/3suji3/today-focus)

### 🍽️ 맛추리 — 취향 기반 맛집 추천 서비스 · 진행 중

> 사용자의 취향과 행동을 기반으로
> 나에게 맞는 식당을 탐색·저장하는 맛집 추천 서비스입니다.

`QA` `Test Design` `Notion` `Jira`

#### QA 담당

* 기획 및 요구사항을 검토하고 테스트가 필요한 조건과 예외 상황 도출
* 주요 기능에 대한 테스트케이스 작성 및 정상·예외 시나리오 검증
* 사용자 핵심 흐름을 기준으로 E2E 수동 테스트 수행
* 결함 발견 후 재현 조건과 결과를 기록하고 수정 이후 재검증
* 기능 정책이 명확하지 않은 항목을 팀과 논의하고 결정 과정 기록
* 네트워크 오류, 데이터 없음, 중복 처리, 권한 거부 등 예외 상황 검증
